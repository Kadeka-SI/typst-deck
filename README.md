typst-deck is a specialized skill that teaches AI agents how to produce high-quality, reproducible presentation decks in Typst 0.15+.
It focuses on real-world reliability rather than flashy packages:

>Landscape 16:9 / 4:3 page setup with correct margins, footers, and page numbering
>Package-free starter template using only built-in Typst features
>Clear design system (accent colors, typography scales, cards, number badges, grids)
>Strict one-idea-per-slide discipline and readable body text sizes
>Asset handling, image best practices, and source attribution rules
>Full CLI workflow (typst compile, typst watch, PNG preview export)
>Visual QA checklist to catch overflow, extra pages, font issues, and contrast problems

The skill is deliberately conservative: it prioritizes clean, editable source files and vector PDF output over untested animations or complex package dependencies. Ideal for agents that need to turn research, reports, or product updates into professional slide decks that users can further edit and recompile locally.
